# Contributing
> [!NOTE] 
> For Contributing, here are the _type of edits_ you can make within the vault for your pull request to be merged.
> - Edits to rectify spelling/grammar edits
> - New information/content
> - Add sources to evidence
> - Edit evidence and errors to make them accurate

Other pull requests may be reviewed in a case-by-case basis, to determine whether they are beneficial.

## How to edit?
1. Make a fork of this repository on your local device/system.
2. Crucial: **Make a new branch, with the branch's name being specific to the issue you are addressing with that branch**
3. Make your edits (on the new branch) :)
4. Submit a pull request to the upstream repo
	1. Make sure your pull request title has the **name of the file(s) changed** 
	2. IN the description, include the type of edit(s) you made (refer to the above section)
> PR title format : Changed file: <name of file changed> <notes, if needed>
