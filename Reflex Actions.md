### Deliberate action vs Reflex action


| Reflex Action                        | Deliberate Action                                    |
| ------------------------------------ | ---------------------------------------------------- |
| Involunatry                          | voluntary                                            |
| Stereotypical response to a stimulus | varied response to a stimulus                        |
| Immediate and fast response          | Slower, as input/decision is required form the brain |
